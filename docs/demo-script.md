# Demo video script (about 3 minutes)

Recorded on the laptop (Lenovo IdeaPad Slim 3i, Iris Xe, 16 GB, no NVIDIA GPU) with the phone next to it. Keep the dashboard visible on the right half of the screen so the task cards, approvals and model calls show up as things happen.

| Time | On screen | Say or do | What it shows |
|---|---|---|---|
| 0:00 | Title card, then the dashboard | "This is Gnosis, a private personal agent for Windows, running on NVIDIA Nemotron through Nebius Token Factory." | The pitch |
| 0:10 | Dashboard | "Hey Jarvis, open Spotify and play some lo-fi." | Voice, wake word, desktop control |
| 0:25 | Dashboard, Notepad | "Open Notepad and write a shopping list: milk, eggs, coffee." | Driving apps through UI Automation, typing safety |
| 0:40 | Dashboard task cards | Type: "Build me a landing page for a coffee shop called Ember and deploy it." Then say: "Remind me at 6 to call Mum." | Parallel tasks; the reminder runs while the coder works |
| 1:00 | Phone | The deploy approval pops up on the phone; tap Approve. | Policy gate, phone companion, Web Push |
| 1:15 | Browser | Open the Vercel link Gnosis posted. "Open it in VS Code." | The coding agent end to end |
| 1:35 | Excel | "Watch me." Do a three-click task, say "done", name the value that changes, approve saving. Then: "Do the monthly report for March." | Teach mode and saved skills |
| 2:05 | Phone over ADB | "Text Arjun that I'm running ten minutes late." Approve. | Android control |
| 2:20 | Dashboard, Memory tab | "What do you know about me?" Show the memory map; forget one fact. | Local memory you control |
| 2:35 | Dashboard, private request | "Privately: summarise my bank statement PDF." Show the model call going to the local model. | Private routing, nothing leaves the laptop |
| 2:50 | Dashboard | Press Ctrl+Alt+J during a task. | Kill switch |
| 2:55 | Title card | Repo link and the hosted demo link. | |

## Before recording

- Set the real Nemotron model IDs (`gnosis models`) and run each scene once.
- Use a test Google account, a test GitHub account, and a contact that's yours for the SMS scene.
- Close anything personal: other Notepad tabs, browser tabs, notifications.
- Turn on do-not-disturb in Windows so only Gnosis notices appear.
